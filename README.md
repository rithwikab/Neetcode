# Neetcode
Tracking the Neetcode Journey
This repository contains my complete NeetCode 150 solutions, written with a focus on deep understanding rather than memorization. For each problem, I document the core pattern, intuition, time/space complexity, and key takeaways to strengthen long-term pattern recognition. The goal of this repo is to build a solid DSA foundation, improve my ability to solve new medium-level problems quickly, and prepare efficiently for technical interviews.
